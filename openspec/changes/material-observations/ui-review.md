# Approved Supervision Screen Review

The existing institutional shell and Materials cards are the accepted visual baseline. The human approved these controls with the concrete requirements through Continue. The implemented flow is verified in docs/material-observations-verification.md.

## Vice principal

Navigation: Material supervision.

Assignment/course selector -> material cards (original author, course, state, current revision and protected open/download) -> Consultar observaciones / Registrar observation.

Observation form: observed title/revision, plain-text Observation, Register. Existing observations show Observada/Respondida/Revisada, creation timestamp, observed revision context, original teacher reply and review timestamp. Respondida offers Marcar como revisada with confirmation; historical closed context shows read-only state.

## Original teacher

Materials card -> Observaciones privadas -> observed revision/context and comment -> Responder observation form when server permits -> retained reply and workflow. Editing remains the separate existing Editar material action. Students and director have no private panel/navigation.

No synthetic role switcher, automatic publication approval, arbitrary recipient selector or new file upload is introduced.
