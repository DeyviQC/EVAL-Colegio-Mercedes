# Academic History

## Requirements

- Director MUST read retained enrollments and assignments. Vice principal MUST read assignment history without enrollment access.
- Teacher MUST read only own assignments. Student MUST read only own enrollments. Client-supplied identity filters MUST be rejected.
- Original period, grade, section, dates, owner and replacement predecessor MUST remain visible across transfer, replacement and closure.
- History MUST be read-only and MUST NOT grant new work, private delivery or file authority. Revoked credentials MUST be denied.
- Discovery MUST use bounded server pagination and exact validated projections. Failure MUST NOT appear as an empty successful history.
