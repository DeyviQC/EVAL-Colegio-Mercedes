Date: 2026-10-08. Predecessor: 6f6b79f. Human request: improve the actual frontend's overall design, intuitiveness, tablet adaptation and lightweight animations using current Internet research. The human explicitly selected a conservative design because tablet model/RAM/Android version are unknown. This authorizes presentation refinement of existing accepted screens, not new domain behavior or role policy.

Preserve the accepted EVAL institutional shell, course navigation, real API clients, permissions and existing workflows. Improve visual hierarchy, spacing, touch controls, responsive navigation, keyboard focus, form readability and feedback. Make existing teacher maintenance controls progressively disclosed and consult their status only when opened. No new dashboard statistics, backend/schema, external assets, UI framework or animation dependency.

Motion is short, finite and limited to opacity/transform, with reduced-motion support. No background animation, blur, video, remote font, continuous polling or persistent layer promotion. Research supports these choices; measured local results do not certify unknown physical tablets.

Screen mapping: existing desktop sidebar -> compact sidebar at tablet widths -> explicit expandable section menu on narrow screens. Keep all role-authorized destinations and active labels. Materials retain primary Open/Download actions; secondary teacher maintenance opens through Options. Login remains the same actual authenticated form, with improved presentation.
