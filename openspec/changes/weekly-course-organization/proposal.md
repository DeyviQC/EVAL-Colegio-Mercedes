# Weekly Course Organization

## Why

On 2026-10-08 the human accepted the blue/mint visual direction and requested weekly organization, following teacher feedback, to help students locate tasks and other course content faster.

## Proposed change

Add a Weeks course view grouping authorized materials and activities in expandable sections. Keep existing content-type views and an Unassigned section for general resources. An independent synthetic preview is available at docs/prototipos/eval-experiencia/azul-menta.html.

## Status and scope

The human accepted the blue/mint visual direction and subsequently accepted the weekly navigation prototype on 2026-10-08 with "si me gusta". This accepts the presented Weeks tab, expandable material/task groups and Unassigned section. Calendar semantics, editing authority and implementation architecture remain pending. No application, schema, API or persistence changes are authorized by this artifact. Weekly grouping must preserve existing course authorization, original assignment ownership, historical access and delivery routing. It must work over the local network without external Internet.
